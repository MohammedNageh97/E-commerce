# MyStore 🛍️

MyStore is a responsive e-commerce website built using HTML, CSS, and JavaScript.

## Features
- Responsive Design
- Product Search
- Category Filtering
- Price Filtering
- Shopping Cart
- Dark Mode
- Checkout Page
- Order Confirmation

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
